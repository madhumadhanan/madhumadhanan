Run this once in the Supabase SQL editor:
create table if not exists pair_messages (
  id bigint generated always as identity primary key,
  pair_key text not null,
  direction text not null check (direction in ('to_device','from_device')),
  kind text not null,
  payload jsonb not null default '{}',
  created_at timestamptz default now()
);
create index if not exists pm_idx on pair_messages (pair_key, id);
alter table pair_messages enable row level security;
create policy anon_rw on pair_messages for all using (true) with check (true);
Note: the pair code is the only secret — share the key privately. Per-pair auth policies come in a later milestone.
